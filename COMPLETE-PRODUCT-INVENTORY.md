### B. Image-generation filters

- Image style: photorealistic, cinematic, illustration, anime, comic, 3D render, watercolor, oil painting, sketch, vector, pixel art, editorial and concept art.
- Subject: person, product, landscape, architecture, food, vehicle, animal, character, logo, environment.
- Composition: close-up, medium shot, wide shot, macro, top-down, centered, rule-of-thirds, panoramic.
- Camera look: focal-length simulation, depth of field, camera angle and perspective.
- Lighting: natural, softbox, studio, dramatic, backlit, rim lighting, low-key, high-key, golden hour, night.
- Color: warm, cool, neutral, monochrome, pastel, vibrant, muted, duotone, selected color palette.
- Mood: happy, dramatic, calm, mysterious, energetic, futuristic, nostalgic, cinematic.
- Aspect ratio: portrait, landscape, square, ultrawide, custom.
- Resolution: supported width/height presets and custom dimensions where the model allows.
- Output count: one image or a supported number of variations.
- Seed: random or fixed seed where supported.
- Prompt adherence: quality settings supported by the selected model.
- Negative prompt: concepts and attributes to avoid.
- Reference strength: influence of an input image where supported.
- Model: image-generation model and version.
- Transparency: opaque, transparent where supported.
- Background: transparent, solid, gradient, generated scene.
- Quality: actual measured resolution, file integrity and relevant model evaluation.

### C. Video-generation filters

- Generation mode: text-to-video, image-to-video, reference-to-video, frame-to-frame, video continuation.
- Duration: permitted duration choices per model.
- Frame rate: supported model or render presets.
- Aspect ratio: 16:9, 9:16, 1:1, 4:5, 21:9 and supported custom ratios.
- Visual style: cinematic, realistic, animation, documentary, commercial, stylized.
- Camera motion: static, pan, tilt, zoom, dolly, tracking, crane, orbit and model-supported movements.
- Shot type: extreme close-up, close-up, medium, full shot, wide shot, establishing shot.
- Motion intensity: static, subtle, moderate, dynamic.
- Subject: person, product, character, vehicle, animal, scene.
- Continuity: preserve subject, preserve environment, reference-guided, generate new scene.
- Lighting: natural, studio, dramatic, low-key, high-key, night, daylight.
- Audio: silent video, supplied audio, generated audio if supported.
- Model: actual available model and version.
- Provider availability: online, offline, busy, requires configuration.
- Job status: queued, running, completed, failed, canceled.
- Quality status: verified, warning, failed.

### D. Video-editor filters

These are both adjustable effects and visual search facets.

Color and image effects: exposure, brightness, contrast, saturation, vibrance, temperature, tint, highlights, shadows, whites, blacks, hue, curves, levels, color wheels, LUTs, selective color, skin-tone correction, vignette, grain, sharpen, blur, glow, bloom and chromatic aberration.

Visual effects: blur, motion blur, Gaussian blur, radial blur, background blur, mask, feathering, green-screen keying, chroma spill suppression, cutout, tracking mask, stabilization, lens distortion correction, noise reduction, denoise and supported compositing effects.

Clip selection filters: duration, source video, scene, detected speaker, selected subject, orientation, camera motion, clip quality, transcript keywords, subtitle language, confidence score and processing status.

Transition filters: cut, dissolve, crossfade, fade to black, fade from black, wipe, slide, zoom, blur transition, match cut and other supported transitions.

Each effect must have an actual implementation using an appropriate renderer or model. Do not merely draw filter controls that do not change the exported media.

## 17. What makes the platform genuinely intelligent?

The natural-language command interface should let a user ask for a finished deliverable in ordinary language.

For example:

> "Use this uploaded Telugu podcast. Find four strong moments, create 9:16 Shorts, track the active speaker, remove long silences, create Telugu captions, make English subtitle versions, generate three thumbnail options, and prepare the files for review."

The AI should then:

1. Understand the instructions and constraints.
2. Identify the correct source file.
3. Construct a structured workflow.
4. Select compatible models and processing tools.
5. Ask for approval when necessary.
6. Execute the real jobs.
7. Report actual job progress.
8. Validate the produced files.
9. Present outputs with clear names and downloadable links.
10. Explain any failed or unavailable step.

The user's request—not a hardcoded example—must drive the workflow.
